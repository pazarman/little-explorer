# Skill 06: STEM Scope & Sequence (ages 2–5)

Use this to (a) ensure every game has a real STEM objective, (b) plan new games against coverage gaps,
and (c) sequence difficulty tiers by child development, not by arbitrary counts.

> **Linked to Skill 01 rubric axis 5 (STEM Coverage Value).** A new game that duplicates a Strong domain
> scores 0 on that axis; one that extends an existing domain scores 1; one that addresses a Gap domain
> at the right developmental tier scores 2. Check this table before proposing or reviewing any new game.

## Sequencing rule

Within a concept, tiers follow the developmental ladder above — not arbitrary counts.
Example (counting): tier 0 = subitize 1–3, tier 1 = count 1–5 with one-to-one correspondence,
tier 2 = count to 10 with the written numeral.

## Highest-ROI gaps to build next (learning value first)

Re-ranked against the table above. The old list is void — it pointed at five filled domains.

1. **Phonological awareness beyond letters** — rhyme, syllable clapping, onset-rime blending.
   Letter Lights covers letter *names and sounds*; none of the pre-reading skills that actually
   predict reading are covered. Still the highest single ROI for ages 3–5.
   *Backlog: Blend-It! (READY), Rhyme Time, Clap the Beat.*
2. **Explicit sequencing / ordering** — "what comes next", putting 3 events in order. The Logic
   row has two memory games and nothing about order, which is a genuine hole rather than a thin patch.
   *Backlog: What Comes Next? (PROPOSED).*
3. **Pattern depth** — extend and create, not just recognise. One game, one mode.
   *Backlog: Pattern Maker (PROPOSED).*
4. **Seriation and capacity** — order 3+ by size; which container holds more.
   *Backlog: Fill It Up! (READY, capacity/conservation — distinct from Fuel Up's set comparison),
   Line Them Up (PROPOSED, seriation).*
5. **SEL in others** — reading a feeling on someone else's face and its cause. Feelings covers her
   own state only. *Backlog: Feelings Friends / How Does Bunny Feel? (PROPOSED).*
6. **Scientific thinking: living/nonliving, weather & seasons.**
   *Backlog: Alive or Not? (READY), Seasons Wheel, Weather Dresser.*

## Objective tags: 7 games are missing one

The rule below is not being kept. These shipped without the required tag, so their domain has to be
inferred from their instruction strings — which is exactly what made the table above drift:

`bike`, `icecream`, `music`, `ocean`, `pets` (petmatch / petcare / petfeed), `rocket`, `story`

Adding a one-line tag to each is a small, high-value chore: it is what makes coverage auditable.

## Required objective tag for every game

Each game (existing or new) should declare, in a comment by its level object:
`Domain · Concept · Age band · Success = (what the child can now do)`.
This makes coverage auditable and ties the rubric's Learning-efficacy axis to a concrete claim.
